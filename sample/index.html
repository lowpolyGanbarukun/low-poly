利用規約（本文）

第1条（適用範囲）

  1. 本規約は、ローポリで頑張るくん（以下「権利者」）が配布する「サンプル商品」（以下「本データ」）の利用条件を定めます。
  2. 本データに含まれるもの：3Dモデル（FBX・GLB・UnityPackage）、テクスチャ（PNG）
  3. 本データを入手または利用した方（以下「利用者」）は、本規約に同意したものとみなします。
  4. 同一の商品として配布される無料版・有料版・支援版には、本規約が同一に適用されます。
  5. 本データに権利者以外が権利を持つ素材（以下「第三者素材」）が含まれる場合、当該素材には、その素材固有のライセンスが優先して適用されます。

第2条（用語）

  1. 元データ　本データに含まれるファイルそのもの。
  2. 改変データ　元データに変更を加えたもの。
  3. 素材　元データまたは改変データの一部（パーツ・テクスチャ・音声・スクリプト等）。
  4. 完成作品　World・ゲーム・アプリケーション・映像作品その他のデジタル作品で、本データが構成要素として組み込まれたもの。
  5. 意図的な提供　利用者が元データ・改変データ・素材を第三者が取得できる状態に置く行為で、次を含みます。
    1. 完成作品に元データ・改変データ・素材を同梱して配布すること
    2. 第三者が取得できる場所に置くこと
    3. 素材単体で配布すること
    4. ダウンロードできる場所に置くこと
  6. 公開先サービスの技術仕様により、第三者が完成作品を解析してデータを取り出せる可能性があることは、前項の意図的な提供には含みません。

第3条（許可する利用）

  1. 改変　モデル・テクスチャ・マテリアルの変更、サイズ変更、ポリゴン削減・最適化、ファイル形式の変換を行えます。
  2. パーツ単位利用　本データの一部のみを、利用者自身のWorld・ゲーム・映像その他の完成作品、および他のモデル・アセットとの組み合わせに使用できます。パーツの改変も前項の範囲で行えます。
  3. 完成作品への組込み　完成作品に組み込んで公開・配布できます。完成作品の無料配布と有料販売のいずれも行えます。
  4. VRChat　Private World、Public World、Community Labs等への公開、商用Worldでの使用を行えます。
  5. VRChat以外のVR・メタバースサービス　使用できます。ただし権利者は、VRChat以外のサービスでの動作を保証しません。
  6. 商用利用　個人による収益化、有料World、ゲーム・アプリの販売、World制作の受託、一般的な広告・プロモーションでの使用を行えます。
  7. 動画・配信・SNS　動画・ライブ配信（収益化・広告収益を伴うものを含みます）、SNS投稿、スクリーンショットの投稿、商品・World・ゲーム・イベントの宣伝に使用できます。
  8. 法人利用　法人も前各項の範囲で利用できます。
  9. クレジット表記　不要です。表記いただける場合は「ローポリで頑張るくん」をご使用ください。

第4条（禁止する利用）

第5条に定める場合を除き、次の行為はできません。

  1. 元データの再配布・再販売
  2. 改変データの再配布・再販売
  3. 素材単体の配布・販売（素材集としての配布・販売を含みます）
  4. 前3号のほか、第2条第5項の意図的な提供に該当する行為
  5. 他の方が同一の商品を購入していることのみを理由として、元データ・改変データ・素材を送受信すること
  6. 本データを利用者自身が制作したものとして表示すること
  7. 第三者の権利を侵害する目的での利用
  8. 法令に違反する利用
  9. 公開先プラットフォームの規約に違反する利用

第5条（共同制作・外部委託）

  1. 利用者は、利用者自身の案件の制作・改変・納品に必要な範囲で、共同制作者および制作代行者（以下「共有先」）に元データ・改変データ・素材を共有できます。共有先が本データを別途購入する必要はありません。
  2. 共有先による本データの使用は、当該案件の作業に必要な範囲に限ります。次の使用は認められません。
    1. 当該案件以外での利用
    2. 個人的な再利用
    3. 再配布・再販売
    4. 別案件への流用
    5. 当該案件の作業終了後に、当該案件と独立して再利用すること
  3. 利用者は、共有を行う場合、次の措置をとってください。
    1. 共有先に対し、本データを当該案件の作業に必要な範囲でのみ使用できること、および前項各号が認められないことを伝えること
    2. 共有先が当該案件以外で本データを利用しないよう管理すること
    3. 共有先が本データを独立して再利用し、再配布し、再販売し、または別案件へ流用しないよう管理すること
  4. 本条の共有によって、共有先が本規約の当事者となるものではありません。共有先による使用について、本規約に基づく義務は利用者が負います。

第6条（センシティブ表現）

  1. 暴力表現、ホラー、怪異、葬儀、時代劇その他の表現を含む作品に使用できます。
  2. 成人向け・性的表現を含む作品に使用できます。この場合、公開先のサービスに年齢制限・センシティブ表示・コンテンツ区分の仕組みがあるときは、その仕組みに従って公開してください。
  3. 前2項は、第4条第8号および第9号の禁止を緩めるものではありません。

第7条（政治的な主題）

  1. 政治的な主題を扱う作品への使用を一律には禁止しません。
  2. 実際にその事実がない場合、権利者、ローポリで頑張るくんその他の関係者（権利者に関係する寺院・宗派を含みます）が、特定の政治的立場・政党・候補者・政治運動を公認・支持・推奨し、またはこれらと提携していると誤認させる利用はできません。

第8条（AI利用）

  1. 次の利用はできません。
    1. 本データを機械学習の学習データとして使用すること
    2. 本データを用いた追加学習・ファインチューニング
    3. LoRAその他の追加学習用データの素材として使用すること
    4. 本データを学習させた学習済みモデル・LoRA・チェックポイント等を配布・販売すること
  2. 利用者が制作補助・技術相談・解析のために、本データまたはその画像を生成AIに入力することはできます。
  3. 前項は、本データの代替物を生成して再配布・再販売する権利を与えるものではありません。この場合も第4条が適用されます。
  4. 第1項は、利用者自身が本データを学習させる行為を禁止するものです。生成AIサービスの仕様により入力内容が当該サービスの学習に利用される場合は、第1項の違反とはしません。

第9条（NFT・ブロックチェーン）

  1. 本データおよびその構成データを、NFTその他のトークンとして発行し、または売買することはできません。
  2. ブロックチェーン技術を使用しているサービスであることのみを理由として、当該サービス上での通常の利用を禁止しません。この場合、第3条第5項が適用されます。

第10条（そのほかの利用）

  1. 本データを用いて制作した画像・映像を、出版物および電子出版物に使用できます。
  2. 本データを用いて制作した画像・映像を、グッズその他の有体物に使用し、販売できます。
  3. 本データをモチーフにした二次創作物を、営利・非営利を問わず配布できます。
  4. 利用者は、本規約上の地位および権利義務を第三者に譲渡することはできません。

第11条（著作権）

  1. 本データの著作権その他の権利は権利者に帰属します。本規約による許諾は、これらの権利を利用者に移転するものではありません。
  2. 第三者素材については第1条第5項のとおりです。

第12条（動作環境・サポート）

  1. 権利者が動作を確認した環境は次のとおりです。Unity 2022.3.22f1（Built-in Render Pipeline）
  2. 権利者は、記載のない環境での動作を保証しません。
  3. 権利者は、改変後の動作、および将来のUnity・VRChatその他のソフトウェアの更新後の動作を保証しません。
  4. 権利者は個人で制作・配布しているため、個別のサポートは行いません。導入方法・ソフトウェアの使用方法・制作方法に関する個別の対応はできません。
  5. ダウンロード商品は、BOOTHの規定によりキャンセル・返金ができません。
  6. 不具合が判明した場合、権利者は修正版として商品を更新することがあります。

第13条（免責）

  1. 権利者は、本データの利用により利用者に生じた損害について責任を負いません。
  2. 前項は、権利者の故意または重大な過失による損害、および法令により責任の免除が認められない場合には適用されません。

第14条（規約に違反した場合）

  1. 利用者が本規約に違反した場合、権利者は本データの利用の許諾を終了することができます。
  2. 許諾が終了した場合、利用者は本データの利用をやめ、手元の元データ・改変データ・素材を削除してください。
  3. 許諾が終了しても、終了前に本規約に従って公開した完成作品は、引き続き公開できます。

第15条（規約の変更）

  1. 権利者は本規約を変更することがあります。
  2. 変更する場合、権利者は本規約を掲載しているページ（https://lowpolyganbarukun.github.io/low-poly/）で告知します。
  3. 本データの利用には、利用者が本データを入手した時点の本規約が適用されます。変更後の本規約が、変更前に入手した本データの利用に適用されることはありません。
  4. 規約Versionは商品Versionとは別に管理します。

第16条（準拠法・お問い合わせ）

  1. 本規約は日本法に従って解釈されます。
  2. 本規約についてのお問い合わせは、BOOTHのメッセージ機能をご利用ください。
